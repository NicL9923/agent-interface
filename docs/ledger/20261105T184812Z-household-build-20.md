# November 5 Household build 20

Build 20 is from commit `ec148947800b3ac0632fb307a3d11fcc43c4751f`, PR #239's build bump. It
carries the native side of these PRs:
- #225: typing into the shared desktop
- #226: portrait compression
- #231: group chat activity, room settings, and routines posting into rooms
- #232: skill lock and MCP reconnect state

`publish-ios.mjs prepare` passed all four App Store profiles. The
[distribution receipt](../evidence/2026-11-05-household-testflight-build-20.json) binds the signed
IPA. Apple confirmed WildBots 1.0 build 20 as installable for both internal Household testers.

The app environment was privately backed up, and the announced build changed from 19 to 20 on
the live release `release-3c8fd16b-20261105T151125Z`. Only `agent-interface.service` restarted.
The [native availability check](../evidence/2026-11-05-native-availability-build-20.json) verified
authenticated bootstrap, native connectivity and build 20, then removed its temporary operator
session.
