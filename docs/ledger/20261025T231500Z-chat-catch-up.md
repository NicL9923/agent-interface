# October 25 chat catch-up on web and iOS

Source fingerprint `sha256:02699255b3577f7766036c002c91f8d8de2a31dd1684c2885a4ad634df83811e`
covers commit `e2c1105` on top of `e282fd2`. Ledger entries are excluded. The host

typecheck, Ruff and the full Python runner (32 files). New coverage includes retry
claims and deterministic retry IDs with shared test vectors, the idle fence that
refuses a retry once another turn starts, search by assistant, group sender
attribution and room watching with its admission cap and early-disconnect cleanup,

discovery and shell UI classes also passed two repeated iterations. An independent
review then found client-only iOS bugs in retry targeting, the shared-computer
screen, opening a chat at a message, search and group notices. Their fixes follow in
a separate change before TestFlight build 16 is archived; this commit's iOS code is
not distributed.
