Branch `t3/prefer-local-tailnet-routes`, on NicolasLaptop, Linux, Node 24.22.2. No live
Hermes, physical phone, simulator or Mac was used: this host has no key to the Mac mini.

- `npm test`: 148 files and 1,981 tests passed. `npm run lint` and `npm run typecheck`: passed.
- `tests/direct-routes.test.ts` runs the real app with real TLS listeners on 127.0.0.1 and
  127.0.0.2, checks the presented certificate against the advertised pin, and covers each
  gate rejection with its `direct_route_refused` reason.
- Mutants, each applied by hand and confirmed red, then restored: the gate's cookie, Origin,
  bearer, registered-route and sign-in-route checks, the renew and logout allowance, the gate
  being skipped, the Tailscale adapter-name check, the virtual-adapter filter, the key and
  certificate pair check, closing a listener whose address went away, LAN-first ordering,
  and the start/close race guard. A redundant tailnet range check survived and was removed.
- `UPDATE_CONTRACT=1 npx vitest run tests/native-contract.test.ts` added
  `native-routes.json`; three unrelated fixtures it rewrote with reordered keys were restored.
