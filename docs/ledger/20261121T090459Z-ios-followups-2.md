confirmed by `grep`, which also found uses it left out: `StatusDock.swift` (the refused and interrupted lines, the

  were left as they were.

## Item 3, #461: group chats in Bubbles

`GroupConversationView` reads the person's `chatStyle`. Classic keeps its rows, now built from shared helpers.
Bubbles passes each message through `GroupBubbles.row`, which uses `ReplyBubbles.segments` on the whole text, so a
card fence stays code as Classic shows it. Others' prose sits in `ReplyBubble` at the leading edge. The person's sits
in `PersonBubble`, which now takes a reply's trailing corners and a layout, at the trailing edge. Tables and code keep
the column's width. The speaker line keeps the avatar, name, routine tag and time, at the speaker's edge, as one
VoiceOver element, with the time under the name at accessibility sizes. Rows drop their card and separator and keep
the selected reply's wash and bar.

Solid uses `GroupBubbles.solidColor`, `#246F59`, which the vector file maps to itself. White text, links and
task boxes read 6.01:1 on it; the quote's text is white and its bar white at 75%, 4.17:1 (half white reached 2.74:1).
iOS draws inline code without a chip, so it is white text at 6.01:1. On the tinted fill a link reads 5.08:1 light and
6.86:1 dark, and a quote 4.89:1 and 5.57:1. `ChatBubblesTests` checks each pair.

`testGroupInkScreens` then showed what that test could not: the empty task box drew in the system's secondary gray
(1.46:1 on the green in light, 2.88:1 in dark), and a link was white with nothing to mark it. Both boxes are now white and
links on a solid fill are underlined, as on the web. Inline code draws in the app's rounded font with no chip, in every
chat, so only its words set it apart.

The quote holding nested lists, on the iPhone SE at Accessibility XXXL, first showed its innermost line truncated to
"Width i…". The text stayed inside its bubble, but part of it was hidden. An offscreen `ImageRenderer` repro on macOS
traced it to `BubbleWidth`, which passed its parent's height offer to the bubble's content. A list row's offer held the
nested item to one line. `BubbleWidth` now offers no height, so the line wraps ("Width / is fine."). The layout is
shared, so reply and conversation bubbles get the same fix. `testABubbleNeverOffersItsContentTheRowsHeight` records
the offers. The person's group bubble also takes the whole row when 16 times the body size is wider than 86%, as the
web's rule does.
