# October 25 performance pass

Source fingerprint `sha256:f78ccb13a59ff13f33ee4d5afea2dc9692dce7415e42020d3f708dbd3af82996`
covers 1150 files at commit `7539f62` on `nic/perf-pass`, based on `383bde4`. The host was
Nicolass-Mini with Node 26.10.0. Hermes did not take part.

The branch shares the bootstrap's Hermes read for 1.5 seconds, ordered so an older read
never replaces a newer one. A new `?inflight=2` stream sends reply growth as deltas, and
`?inflight=1` stays byte-for-byte unchanged for the iOS app. Finished transcript turns and
the composer no longer re-render on each streaming update. Animated avatars share one frame
loop. The assistant menu's popup library loads after first paint, and the build fails if it
returns to the entry. The service worker installs only what the first visit loads and warms
the rest on request from the page. Focus no longer re-reads the bootstrap within 5 seconds
of a successful read. Closing the Hermes runtime mid-connect no longer opens a socket.

never sent a request. Run three at a time on Node 24.21.0, the suite failed 3 of 9 runs.

## Review

GPT-6.1 Sol reviewed the full diff at high effort and found four defects and two doc
errors. They were an older read overwriting a newer snapshot, a failed refresh keeping the
focus throttle, two cold right-clicks opening two menus, and warming outside the worker's
lifetime. All were fixed with tests that fail on the earlier code, and a re-check approved
them. Browser checks then found that installing every file before storing any hung over
HTTP/1.1. The fix stores each file as it arrives. Its review found that a failed reinstall
of the active release would delete the live cache, which was also fixed.

Not exercised: a physical phone, Safari or WebKit, a real Hermes stream using deltas, and
a production HTTP/2 deployment.
