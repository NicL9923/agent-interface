# November 26–27 Python removal (`Python` → `TypeScript / Node / Bun`)

Replaced all active Python runtime helpers, deploy/ops scripts, iOS build/validation tools, `check-all`, and Python test suites with TypeScript/ESM running on Node and Bun 1.4.5, and removed `ruff.toml`, `.github/requirements-ci.txt`, `test:py`, `lint:py`, and the Python CI / `pip-audit` jobs.
