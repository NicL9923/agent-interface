# November 12 Household build 27

Build 27 is from commit `faeca94293178949506d765160ccb3d41e1876f6`, which includes #383's build bump. It carries the
native side of #376: loading earlier messages reads only the page before the first message
(`before=<id>&turns=20`) and puts it in front of the conversation, instead of reading everything from there to the
newest message again.

On the Mac mini, `publish-ios.mjs prepare` passed. The agent ran `archive 1.0 27` from a detached worktree at
`faeca942` under the Mac lock (11.6 min queued, 45 s archiving), then `upload` once (8 min 40 s) and `distribute`
(about 23 min, mostly Apple's processing). The IPA's SHA256 is
`22a31481c82709f4bc9ce8c073446a638f3433f71d20ba99cd4c0399704b9214`; the distribution receipt stays private on the Mac.
Apple confirmed WildBots 1.0 build 27 as installable for both internal Household testers at 23:45:25 UTC. The build
expires on February 10, 2027.

The app environment was privately backed up, and the announced build changed from 26 to 27 on the live release
`release-53ee15de-20261112T234308Z`. Only `agent-interface.service` restarted; the gateway kept its process. The
[native availability check](../evidence/2026-11-12-native-availability-build-27.json) verified authenticated
bootstrap, native connectivity and build 27, then removed its temporary operator session.
