# October 22 Household build 13

PR #179 merged at the commit recorded in the
[distribution receipt](../evidence/2026-10-22-household-testflight-build-13.json), which binds the signed IPA. Apple
confirmed WildBots 1.0 build 13 as installable for both internal Household testers. The
app environment was privately backed up, the announced build changed from 12 to 13, and
only the web app service restarted; the release and Hermes were unchanged. The
[native availability check](../evidence/2026-10-22-native-availability-build-13.json)
verified authenticated bootstrap, native connectivity and build 13, then removed its
temporary operator session.

Build 13 keeps home live once the roster is after an offline launch, and carries the
iOS test reliability work. Native validation ran on the Mac mini: 360 unit tests and
the full 56-test UI suite passed. The Cmd+F after Cmd+1 step is a recorded known issue
(#178). A physical-phone cold launch was not exercised.
