# November 15 Linux WebKit validation

Source fingerprint `sha256:1dd33881e69375b10ee573c45d88d50095ac95629c33f55a220b1a634c75a04d`. The Playwright 1.65.0 Noble container ran on Colima with its own installed dependencies and build. No physical device or real push service was exercised.

The initial Linux WebKit smoke case failed because the fixture recorded WebKit's unsupported `interactive-widget` viewport warning as a console error. Filtering that exact WebKit message made the smoke case pass. The first full run then failed the photo test because Linux WebKit encoded WebP where macOS WebKit had used JPEG; the test was changed to detect the encoder. A later full run exposed an intermittent cancelled conversation request in a returning-member reload test. Waiting for the previous document's startup network requests to settle made both returning-member tests pass. These failures supplied the red runs for the affected assertions and fixture.

The resulting full Linux WebKit run passed 82 tests with three existing capability skips in 2.3 minutes. A Linux Chromium sanity run passed the smoke, photo and both returning-member cases, four tests in 8.6 seconds. The local macOS check-all results are reported in the PR after the run completes.

The subsequent Mac `check-all --keep-going` passed typecheck, lint, ruff, build and the combined e2e suite (167 passed, three skipped; 4 minutes 21 seconds). Its unit suite passed 4,060 tests and failed the same three cases requiring the unconfigured 127.0.0.2 alias. Python was skipped because its inputs did not change relative to main.
