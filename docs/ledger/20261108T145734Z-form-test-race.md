# November 8 form test race

Branch `t3/form-test-wait-editable`, on NicolasLaptop, Linux, Node 24.22.2.

CI run 42491974120 (PR #268, Node `.node-version` job) failed `form replies > shows its own answers
as sent when the server's text is theirs`: the card showed "Sent" from elsewhere with no answers.
Cause: `fill()` ran while the form's opening lookup still had its fields disabled. The typed
destination landed, the Pace and dog clicks didn't, so the form sent "Relaxed / No", which didn't
match the server's text. The card was right; the test filled too early.

- Reproduced by holding the opening lookup 300 ms of real time: the test failed. With `fill()`
  waiting for `aria-busy="false"`, the same held lookup passed. The delay was then removed.
- `npx vitest run`: 149 files and 2,074 tests passed. `npm run lint`: passed.
