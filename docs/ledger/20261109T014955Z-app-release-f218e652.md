## Runtime and iOS build

Before this release, `agent-interface.service` moved from Node 24.21.0 to 24.22.2 with the
`20-node.conf` drop-in described in [Hosting](../Hosting.md), because `package.json` now requires
`^24.22.2`. The host's binary matched the official `node-v24.22.2-linux-x64.tar.xz`, checked
against `SHASUMS256.txt`. After a daemon reload and restart, `/api/health/ready` returned 200
and the process ran the new binary. The release was prepared with `--node` set to that path.

The first qualification failed because PM Chromium could not start for the local-network probe.
The live receipt had selected `/opt/google/chrome/chrome`. A second run with that
`--computer-probe-browser` passed.

TestFlight 1.0 (23), archived from `a809c55`, reached the Household group on November 9 with
two testers; Apple's processing finished before distribution. `IOS_APP_LATEST_BUILD` moved from
21 to 23 in `shared/app.env` before activation, so the update banner announces build 23.
