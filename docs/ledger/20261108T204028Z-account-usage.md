## Independent review

GPT-6.1 Sol reviewed `9648375..209175a` and found eleven defects, three P1: account keys that did not
bind the credential read or spent, retried resets that could spend twice, and alias sign-ins that
escaped the reset lock. `f2b1fc5` fixed them; a scoped re-review confirmed eight fixed and found four
more (shared Nous keys across profiles, explicit ChatGPT fallbacks sent to the pooled route, expired
tokens that never refreshed, pending alias reads after a reset), fixed in `ad4d013`. A final review of
`ad4d013` and the iOS commit found Hermes's own usage resolver can answer a failed refresh with another
pooled ChatGPT account and move an explicit fallback to another gateway. Reads are now read-only and renew
an expiring pooled token only through its own pool entry, checked to be the same account. Resets are
spent by the add-on with Hermes's guard and outcome helpers and the account's own token, and send the
request ID as ChatGPT's `redeem_request_id`, so a consume whose answer was lost is resent safely and
ChatGPT answers `already_redeemed`. It also found an identity-less pending alias, a late iOS read
overwriting a reset and a stale iOS menu line; all fixed with tests broken by hand. Listing still
calls `load_pool()`, whose idempotent seeding Hermes's own model picker runs on every catalog read;
the reviewer recorded that as a partial and it is accepted.
