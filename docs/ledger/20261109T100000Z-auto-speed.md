## What changed

Auto joins Normal, Fast and Ultrafast as a conversation speed on the web and iOS pickers and in the
shared `serviceTiers` contract. Hermes's `fast` key accepts `auto` but reports it as `normal` from
`config.get`, and checks the model only for Fast and Ultrafast. The server therefore reads Auto through
a `config.set` status read, asks Hermes for Fast first so an unsupported model refuses Auto, and puts
the earlier speed back if Auto then fails. See `HermesCapabilityMatrix.md` for the source lines.
