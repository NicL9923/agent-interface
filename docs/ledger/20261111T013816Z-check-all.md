# November 10 check-all runs the whole check battery

Branch `t3/check-all-tool`, from `origin/main` at `785f4f2`. Checks ran on Fedora
(Linux x64, Node 24.22.2, Python 3.14.10, ruff 0.17.3, Playwright Chromium) at commit `2ba3626`, which this
entry follows. No application, Hermes, iOS or deploy code changed. The change is
`.agents/tools/check-all` (logic in `check_all.py`), `scripts/precache-plan.mjs` and `e2e/ports.ts`, with
their tests and docs. Nothing was exercised on macOS: the lock uses `flock` and `socket`, which behave the same
there, but no Mac ran it.

## Change

- `.agents/tools/check-all` runs typecheck, lint, ruff, test, build, e2e and py in that order and prints one
  table. It holds a machine-wide `flock` slot for test, e2e and py, and a lock on the e2e app and control port
  pair.
- `scripts/precache-plan.mjs` matches the terminal and remote desktop packages by directory name, so a
  symlinked `node_modules` (Vite records `../../shared/node_modules/...` or an absolute path) no longer fails
  the build.
- `e2e/ports.ts` keeps 4173 without the tool and refuses a malformed `E2E_PORT`.

## Reproduction of the symlink trap

Before the fix, a worktree whose `node_modules` was a symlink to another checkout's failed `npm run build`
with "The build has no terminal or remote desktop chunks to keep out of the install cache." The manifest keys
were `../../../../../../home/nic/.t3/worktrees/agent-interface/<checkout>/node_modules/@novnc/novnc/core/rfb.js`.
After the fix the same worktree builds, and `Built service worker 79a0897ff2877210 with 64 installed files, 31
cached in the background, 3 on first use and 10 never cached.` matches the plain checkout's line exactly.

The survivor removes the cached-venv fast path before the install lock. The same check runs again inside the
lock, so the result is identical and only the lock is taken needlessly. It stays as a fast path.

Two earlier gaps the mutation run found are fixed: a Python file renamed away was listed only by its new name
(`--no-renames` now), and the test for a moved base had two files with identical content, which git read as a
rename. A first mutation pass also reported two false survivors that were stale `.pyc` files from rewriting a
file within one second; the final pass ran with `PYTHONDONTWRITEBYTECODE=1`.
