With the original fake response of `null`, `npx vitest run tests/worker-opens-ui.test.ts -t 'opens a routine'` failed with `Cannot read properties of null (reading 'some')` and the empty-state assertion failed. Returning the API's empty array made the same test pass.

The existing uncertain-create focus assertion failed intermittently with the animation-frame callback before the fix, including in the check-all log at 12:34.
