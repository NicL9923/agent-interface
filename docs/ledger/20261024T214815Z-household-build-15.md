# October 24 Household build 15

Build 15 is from release commit `1d43bbf8cdbbb899a85a3d980d4f88b21ba71e28`, which includes PR #191 and PR #192. The
[distribution receipt](../evidence/2026-10-24-household-testflight-build-15.json) binds the signed IPA. Apple
confirmed WildBots 1.0 build 15 as installable for both internal Household testers. The
app environment was privately backed up and the announced build changed from 14 to 15.
Only the web app service restarted. The release and Hermes were unchanged. The
[native availability check](../evidence/2026-10-24-native-availability-build-15.json)
verified authenticated bootstrap, native connectivity and build 15, then removed its
temporary operator session.

Build 15 is the first with the notification service extension. Its App Store profiles were
regenerated after Time Sensitive and Communication Notifications were turned on and the
App Group was linked to `dev.agentinterface.ios.AgentInterfaceNotifications`. The publish
tool verified the App Group in every profile and signed bundle, and production push and both
notification entitlements on the main app. Native validation is recorded in
[native iOS features](20261024T005725Z-native-ios-features.md) and
[unread, renewal and performance](20261024T022939Z-unread-renewal-performance.md). The
build was not exercised on a physical phone.
